Moss Launcher ベータ版 0.1.0-beta.1 / Windows 10・11 x64
作成日：2026-10-06

Prism Launcher 11.1.1を基にした独立した試験版です。
Mojang・Microsoft・Prism Launcherの公式製品ではありません。
アプリ内の「11.1.1」はベースとなるPrismのバージョンです。

セットアップ
・MossLauncher-0.1.0-beta.1-windows-x64-setup.exeを開き、案内に従ってください。
・現在のWindowsユーザー専用です。管理者権限を要求しません。
・標準の保存先は %LOCALAPPDATA%\Programs\Moss Launcher Beta です。
・スタートメニューに登録します。デスクトップのショートカットは任意です。
・必要なQt・Visual C++のDLL、対応するソース、ライセンスを同梱しています。
・Minecraft本体やゲーム用Javaは含みません。初回案内で日本語とJavaを選んでください。
・旧MossやPrismのフォルダには上書きしません。実行中のアプリを強制終了しません。
・既存の別アプリがあるフォルダへの上書きインストールは拒否します。

起動構成・ワールドの保存
・インストール先のUserDataに、設定・起動構成・ワールド・MODを保存します。
・更新インストールではUserDataに含まれるファイルを上書きしません。
・アンインストールではアプリのファイルと登録だけを削除し、UserDataは残します。
・念のため、ワールドなどの大切なデータは別途バックアップしてください。
・以前のポータブル版の起動構成は、自動では移行しません。
  移行するときはMossとMinecraftを閉じ、双方のUserDataをバックアップしてから、
  旧版のUserDataの中身を新しいインストール先のUserDataへコピーしてください。
  インスタンス内で絶対パスを指定している場合は、コピー後に設定も確認してください。
・UserDataにはアカウントのトークンが含まれることがあります。他人へ渡さないでください。
  このセットアップには作成者の起動構成・ワールド・アカウント情報を含めていません。

現在の機能
・起動構成の管理、Javaの自動検出・選択、Forge・Fabricなどの導入。
・ModrinthでのMOD検索・導入、リソースパック・シェーダーの管理。
・MODの「確認」で必須の前提MODを調べ、一緒に導入するか選択できます。
  前提MODを外して進むときは、起動できない可能性について再確認します。
・ローダーの選択画面には対象のMinecraft版とバージョンの意味を表示します。

ベータ版の制限
・Microsoft/Minecraft APIの利用承認は確認できていません。
  実アカウントでのログイン、Minecraft起動、オンラインMOD導入は未検証です。
  インストールできても、現時点でログインして遊べることは保証しません。
・CurseForgeのAPIキーは同梱していません。承認と正規の利用設定が別途必要です。
・トークン保存はPrism由来のJSON形式で、Windowsによる暗号化保存は未実装です。
・前提MODは配布元の必須依存情報に基づきます。互換性や手動導入済みMODの
  判定を完全に保証するものではありません。任意の追加MODは自動追加しません。
・自動更新は無効です。アップデートは新しいセットアップで行います。
・コード署名は付いていません。Windowsが未確認の発行元として扱う可能性があります。
  警告を無視する操作は自動化しません。配布元とSHA256を確認してください。
