Moss Launcher (Prism-based) / Windows x64
Prism Launcher 11.1.1を基にした独立した派生版です。
Prism公式版ではなく、Prismプロジェクトの承認・提携はありません。

起動
1. 配布フォルダを丸ごと置き、mossprism.exeを起動します。
2. 初回案内で日本語、テーマ、Javaの設定を選びます。
3. 「インスタンスを追加」でMinecraft版やMODパックを選びます。
4. 「編集」のバージョン画面からForge / Fabricなどを導入できます。
5. MOD画面からModrinthの検索・追加・更新を利用できます。

EXEだけを取り出さないでください。隣のDLL・jars・plugins等も必要です。
Pythonは不要です。Minecraft本体とゲーム用Javaは同梱しません。
Microsoft Visual C++ x64ランタイム（14.51）の再配布用DLLも同梱しています。
PCへのシステムインストールや環境変数の変更は行いません。
MSVC-RUNTIME-NOTICE.txtの注意事項も参照してください。
Prism本来の購入済みアカウント確認は維持しており、認証は回避しません。

Java 26などを手動で使う
「編集」→「設定」→「Java」で構成別のJava指定を有効にし、
「自動検出」で一覧から選べます。必要に応じて、Prism本来の
「Java互換性チェックを省略」を有効にすると指定版以外も試せます。
実行可能でもMOD・ローダーとの互換性を保証するものではありません。
「テスト」でJava・メモリ・追加引数を確認できます。

認証・CurseForgeについて
PrismのMicrosoft / CurseForge / Imgur用のキーは流用していません。
この認証準備版には所有者が提示したMoss用の公開MicrosoftクライアントIDを組み込みました。
Azureの戻り先設定とMinecraft APIの利用承認は別途必要です。MICROSOFT-SETUP.txtを参照してください。
利用者ごとにアプリ登録をする方式ではありません。実アカウントのログインは未検証です。
CurseForge連携には独自の正規の利用登録、承認されたAPIキーと利用条件確認が必要です。
「設定」→「サービス」のAPI設定欄で設定できます。必要に応じて再起動してください。
準備がない状態では、そのサービスの機能は使えません。
秘密のAPIキー・クライアントシークレット・トークンをソースや配布ZIPへ含めないでください。
MicrosoftクライアントIDは公開識別子であり、秘密の認証情報とは異なります。
アカウント保存はPrism由来のJSON形式で、Windows資格情報保護は未実装です。

保存先・旧版との関係
ポータブル版として、EXEと同じフォルダ内のUserDataに保存します。
インスタンス、ワールド、MOD、設定、アカウント情報もその配下です。
既存のPrismやPython製Mossの設定・ワールドは変更していません。
旧Mossからの構成変換・自動移行は行っていません。
別の場所へ移す場合は、UserDataを含めて配布フォルダを丸ごと移してください。
認証情報を保存したUserDataを他人に配布しないでください。

公式版との違い
画面構成・通常の操作と機能の実装はPrismのソースを使用しています。
名称、Mossマーク、独立した保存先、派生版表示は変更しています。
Prism公式版に上書きされないよう、公式更新チャンネルは無効です。
Prism公式の不具合報告先への自動導線は無効です。
その他の画面の外観はOS・テーマ・Qt版・翻訳により差が出ることがあります。
通常の起動は管理者権限不要です。Windowsのリンク作成など、権限が必要な
機能を明示的に使う場合に限り、Prism由来の補助処理が確認を要求します。
自動テストから、この確認を繰り返すリンク作成テストを除外しました。
